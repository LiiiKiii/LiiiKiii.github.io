Supervised Learning

Supervised learning is a machine learning setting in which a model learns a mapping from inputs to labelled outputs. The training dataset contains examples together with the correct answer, and the model is optimized to reduce prediction error.

Common supervised tasks include:
- classification, such as spam detection or image recognition
- regression, such as price prediction or demand forecasting

Key concepts:
1. Training set, validation set, and test set
2. Loss functions such as cross-entropy and mean squared error
3. Generalization to unseen examples
4. Overfitting, underfitting, and regularization
5. Evaluation metrics such as accuracy, precision, recall, F1, and RMSE

Representative algorithms:
- linear regression
- logistic regression
- support vector machines
- decision trees and random forests
- neural networks

In practice, supervised learning is one of the most common entry points into AI because it links model design directly to observable task performance. It also provides a foundation for understanding optimization, feature learning, and model evaluation in later deep learning systems.
