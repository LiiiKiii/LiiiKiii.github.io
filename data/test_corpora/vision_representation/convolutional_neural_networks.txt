Convolutional Neural Networks

Convolutional neural networks, or CNNs, are deep learning models designed to process grid-like data such as images. They are built around convolution operations that apply learnable filters across local regions of an input.

Key ideas:
1. Local receptive fields capture nearby visual patterns
2. Weight sharing makes the model efficient
3. Pooling layers reduce spatial size and add invariance
4. Deeper layers learn increasingly abstract features

Why CNNs matter:
CNNs became foundational in computer vision because they automatically learn features such as edges, textures, shapes, and object parts directly from raw pixels. This reduced the need for manual feature engineering.

Applications include:
- image classification
- object detection
- semantic segmentation
- face recognition
- medical image analysis

Even though transformers are increasingly important in vision, CNNs remain a core concept for understanding deep learning on images and the historical development of modern visual AI systems.
